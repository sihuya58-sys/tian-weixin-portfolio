# 储能电站「谷充峰放」套利收益测算模型

> **一句话简介**：搭建 100MWh 储能电站 10 年期全周期财务模型，回答一个问题——在当前电价和成本下，储能纯套利模式到底能不能赚钱。

## 背景

储能行业有一个公认的痛点：政策鼓励建储能，但纯套利模式的经济性长期存疑。一个储能电站动辄投资上亿元、运营十年，决定成败的关键变量（峰谷价差、单位投资成本、充放电效率）每天都在变。没有一套量化的测算模型，投资决策只能拍脑袋。

## 做了什么

- 基于陕西省分时电价（峰 1.2 元 / 谷 0.3 元，价差 0.9 元/kWh），搭建 100MWh 储能电站 10 年期财务模型，含 5 个工作表：
  - 测算主页（交互式参数区，改参数自动重算）
  - 逐年收益表（含容量衰减，10 年后容量约 83%）
  - 现金流与 IRR（NPV / IRR / 静态与动态回收期）
  - 敏感性分析（6 维度龙卷风图）
  - 情景分析（乐观 / 基准 / 悲观三情景）
- 六维敏感性分析：峰谷价差、单位投资成本、折现率、年运营天数、充放电效率、年衰减率
- 盈亏平衡测算：反推"什么条件下这个项目才能回本"
- Python（openpyxl）自动生成 Excel 模型，公式与脚本双引擎

## 成果数据

- 单次循环毛利 **7.81 万元**（毛利率 **72.2%**）
- 基准情景 **IRR 3.2%**、**NPV -3,552 万元**、静态回收期 9-10 年 → **当前条件下纯套利不具备投资价值**（IRR < WACC 8%）
- 三情景 IRR：乐观 **15.1%** / 基准 **3.2%** / 悲观 **-8.1%**
- 敏感性排序：**峰谷价差第一**（收窄 20%，NPV 从 -3,552 万降至约 -8,000 万）、单位投资成本第二
- 反直觉发现：充放电效率从 90% 提到 96%（行业前沿水平），NPV 仅改善约 **1,500 万元**——关注政策和成本比关注技术效率更有投资价值
- 盈亏平衡点：价差扩大至约 **1.05 元/kWh**，或单位投资降至约 **1.45 元/Wh**

## 技术栈

- Python（openpyxl 自动生成 Excel 财务模型）
- Excel 公式建模（IRR / NPV / 数据表敏感性分析）
- 财务分析：折现现金流、龙卷风图、情景分析、盈亏平衡分析

## 如何运行

- **看结果**：直接打开 `储能套利收益测算模型_v2.xlsx`，在「测算主页」修改参数自动重算
- **重新生成模型**：`python build_energy_storage_model_v2.py`
- 详细分析见 `储能套利分析报告_v2.md`
