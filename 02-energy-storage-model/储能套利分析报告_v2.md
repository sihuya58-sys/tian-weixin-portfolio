# 储能电站「谷充峰放」套利收益测算 —— 分析报告 v2.0

## 1. 模型概述

基于陕西省分时电价（峰1.2元/谷0.3元，价差0.9元/kWh），搭建100MWh储能电站10年期全周期财务模型。模型包含5个工作表：测算主页（交互式参数区）、逐年收益表（含容量衰减）、现金流与IRR（NPV/IRR/回收期）、敏感性分析（6维度龙卷风图）、情景分析（乐观/基准/悲观三情景）。

## 2. 关键假设

| 参数 | 基准值 | 说明 |
|------|--------|------|
| 峰谷价差 | 0.9元/kWh | 陕西一般工商业参考 |
| 储能容量 | 100MWh | 交流侧可用（DoD=95%） |
| 充放电效率(RTE) | 90% | 往返效率，充100度→放90度 |
| 年运营天数 | 330天 | 每天1次谷充峰放 |
| 单位投资 | 1.8元/Wh | 总投资1.8亿元 |
| 年运维费率 | 2% | 年运维费360万元 |
| 折现率 | 8% | WACC加权平均资本成本 |
| 所得税率 | 25% | 一般企业税率 |
| 年容量衰减 | 2% | 10年后容量约83% |

## 3. 测算结果

### 单次循环（第1年基准）

| 指标 | 数值 |
|------|------|
| 有效可用容量 | 95,000 kWh |
| 充电量（电网取电） | ~100,139 kWh |
| 充电成本 | **3.00万元** |
| 放电量（上网售电） | ~90,125 kWh |
| 放电收入 | **10.82万元** |
| 单次循环毛利 | **7.81万元**（毛利率72.2%） |

### 年度与全周期

| 指标 | 数值 |
|------|------|
| 第1年毛利 | 2,577万元 |
| 第1年净利润（税后） | 1,663万元 |
| 10年累计净利润 | — |
| **IRR（内部收益率）** | **3.2%** |
| **NPV（净现值@8%）** | **-3,552万元** |
| 静态回收期 | ~9-10年 |
| 动态回收期 | >10年（NPV未回正） |

### 核心判断

**在当前陕西0.9元/kWh价差和1.8元/Wh投资成本下，纯套利模式不具备投资价值**（IRR=3.2% < WACC=8%，NPV负值）。这恰恰印证了业界将"储能如何参与现货套利"称为最大痛点的原因。

## 4. 敏感性分析 — 龙卷风图

| 排序 | 变量 | 变化范围 | NPV波动幅度 | 关键程度 |
|------|------|----------|-------------|----------|
| 1 | **峰谷价差** | 0.72~1.08元/kWh | **最大** | ★★★★★ |
| 2 | 单位投资成本 | 1.53~2.07元/Wh | 第二 | ★★★★ |
| 3 | 折现率 | 5%~11% | 第三 | ★★★ |
| 4 | 年运营天数 | 297~363天 | 第四 | ★★★ |
| 5 | 充放电效率 | 84%~96% | 第五 | ★★ |
| 6 | 年衰减率 | 1%~3% | 最小 | ★ |

**解读**：峰谷价差是命门——价差收窄20%，NPV从-3,552万降至约-8,000万。投资成本是第二关键——成本每降0.1元/Wh，NPV改善约1,000万元。

**反直觉发现**：充放电效率的影响远小于价差和成本。效率从90%提到96%（行业前沿），NPV仅改善约1500万元。在这个行业，**关注政策和成本比关注技术效率更有投资价值。**

## 5. 情景分析

| 指标 | 乐观情景 | 基准情景 | 悲观情景 |
|------|----------|----------|----------|
| 峰谷价差 | 1.05元/kWh | 0.90元/kWh | 0.75元/kWh |
| RTE效率 | 93% | 90% | 86% |
| 投资成本 | 1.50元/Wh | 1.80元/Wh | 2.10元/Wh |
| **IRR** | **15.1%** | **3.2%** | **-8.1%** |
| **NPV** | **+6,885万元** | **-3,552万元** | **-12,722万元** |
| 投资结论 | 强烈推荐 | 不推荐 | 严重亏损 |

**弹性评估**：从悲观到乐观，NPV跨度近2亿元，IRR从-8%到+15%。储能套利是一个**高弹性、高不确定性**的商业模式——项目成败高度依赖外部条件。

## 6. 盈亏平衡分析

要使NPV=0（IRR=WACC=8%），需要以下条件之一：
- 峰谷价差扩大至**~1.05元/kWh**（较当前+17%）
- 或单位投资降至**~1.45元/Wh**（较当前-19%）
- 或每天实现**1.5次**完整循环（谷充→早峰放→午平充→晚峰放）
- 或以上条件的组合

当前行业趋势（电池成本快速下降+电力市场化改革深化）正在**同时改善两个最关键变量**，储能套利的盈亏平衡点正在逼近。

## 7. 简历表述建议

> 搭建100MWh储能电站全周期套利收益测算模型，涵盖IRR/NPV/动态回收期等财务指标。运用龙卷风图和情景分析方法，量化峰谷价差、投资成本、充放电效率、容量衰减等6个关键变量对项目收益的敏感性，识别出峰谷价差为第一驱动因子（NPV弹性系数最高），盈亏平衡价差约1.05元/kWh。通过乐观/基准/悲观三情景对比，评估储能参与电力现货套利的收益边界条件与投资决策门槛。
