## 🎯 项目解决了什么问题？

电力交易市场数据分散在交易中心官网、行业媒体、政策文件中。一个分析师要回答"最近电价走势如何"这个问题，需要：

1. 手动下载多份PDF公告
2. 逐份提取关键数据到Excel
3. 手工画图、写报告
4. 每次数据更新后全部重做一遍

**这个项目把以上流程代码化了**——修改一组数据，一键重新生成全部输出。

## 🏗️ 项目结构

```
陕西电力市场分析/
├── README.md                          ← 📖 你正在看的文件
├── requirements.txt                   ← 📦 依赖清单
├── data_collection.py                 ← 📊 数据定义层（改数据只改这里）
├── analysis.py                        ← 🔧 分析引擎（一键生成所有输出）
│
├── 陕西电力市场交易数据分析.xlsx       ← 📋 输出：9个Sheet完整数据
├── 陕西电力市场电价趋势分析报告.md      ← 📄 输出：分析报告（可转PDF）
│
├── chart1_月度批发均价走势.png         ← 📈 输出：价格走势图
├── chart2_市场结构与批零价差.png       ← 📊 输出：市场结构图
└── chart3_发电侧价格电量分析.png       ← 📉 输出：发电分析图
```

**设计原则**：数据与分析分离。换一个省份的数据只需修改 `data_collection.py`，`analysis.py` 不需要动。

## 🔑 核心分析结论

| 指标 | 1月 | 7月 | 变化 | 解读 |
|:---|---:|---:|---:|:---|
| 批发均价 | 359.76 元/MWh | 329.50 元/MWh | **↓8.4%** | 新能源+煤价双杀 |
| 零售均价 | 367.54 元/MWh | 362.90 元/MWh | ↓1.3% | 降价传导不畅 |
| 批零价差 | 0.0078 元/kWh | 0.0334 元/kWh | **↑4.3倍** | 售电公司截留红利 |
| 光伏电量 | — | — | **+50.23% YoY** | 结构性降价力量 |

**四个驱动因素**：新能源装机暴增 → 零边际成本电量涌入 → 出清价格被压低 → 电煤降价叠加 → 批发电价单边下行。
