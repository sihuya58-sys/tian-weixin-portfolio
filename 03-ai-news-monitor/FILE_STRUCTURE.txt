项目文件结构
===============

├── README.md ⭐
│   └─ 完整使用指南
│
├── PROJECT_SUMMARY.md
│   └─ 项目概览与技术亮点
│
├── FILE_STRUCTURE.txt
│   └─ 本文档
│
├── .env.example ⭐
│   └─ 环境变量模板（复制为 .env 并填入密钥）
│
├── requirements.txt ⭐
│   └─ Python 依赖清单
│
├── ════════════════════════════════════════
│   【源代码文件】
│   ════════════════════════════════════════
│
├── config.py ⭐
│   ├─ API 密钥读取（从 .env）
│   ├─ RSS 源列表配置
│   ├─ 轮询间隔设置
│   ├─ DeepSeek 系统提示词
│   └─ 配置验证函数
│
├── rss_crawler.py
│   ├─ feedparser RSS 解析
│   ├─ 单源/多源抓取
│   ├─ 内容有效性检查
│   └─ 异常处理和重试
│
├── ai_analyzer.py
│   ├─ DeepSeek API 调用
│   ├─ 系统提示词应用
│   ├─ 结构化输出解析
│   └─ 重试机制
│
├── storage.py
│   ├─ SQLite 数据库初始化
│   ├─ GUID 去重检查
│   ├─ 新闻项目记录
│   └─ 推送状态更新
│
├── push_sender.py
│   ├─ Telegram Bot 推送

│   ├─ 消息格式化
│   └─ 错误处理
│
├── main.py ⭐
│   ├─ 系统主程序
│   ├─ 模块协调
│   ├─ 轮询循环
│   └─ 信号处理（Ctrl+C）
│
└── demo.py
    └─ 演示模式（模拟数据，无需真实 API）


核心工作流
===========

RSS 爬虫 (每60秒)
      ↓
   抓取最新文章
      ↓
   检查 GUID 是否已处理
      ↓
   DeepSeek AI 分析
      ↓
   是否重大利好/利空？
      ├─ YES → 推送到 Telegram
      └─ NO  → 存储但不推送
      ↓
   更新数据库状态
      ↓
   等待下一轮...


快速启动命令
=============

1. 安装依赖
   pip install -r requirements.txt

2. 配置密钥
   复制 .env.example 为 .env，填入 API 密钥

3. 启动系统
   python main.py
