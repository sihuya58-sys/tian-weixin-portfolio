# 项目完成总结

## 核心源代码

| 文件 | 职责 |
|------|------|
| `config.py` | 配置管理，API 密钥从 .env 读取，RSS 源与轮询间隔配置 |
| `rss_crawler.py` | RSS 解析和轮询抓取，异常处理与重试 |
| `ai_analyzer.py` | DeepSeek AI 分析：判断新闻对代币的重大利好/利空 |
| `storage.py` | SQLite 数据库，GUID 去重逻辑 |
| `push_sender.py` | Telegram / PushDeer 双渠道推送 |
| `main.py` | 主程序，协调所有模块，轮询循环 |
| `demo.py` | 演示模式：无需真实 API，展示系统效果（模拟数据） |

## 核心功能实现

### 1️⃣ 数据收集层
- **RSS 源**：CoinDesk 官方新闻源 + 价格源
- **轮询机制**：可配置间隔（默认 60 秒）
- **连接处理**：自动重试、超时控制
- **错误恢复**：单个源失败不影响其他源

### 2️⃣ AI 甄别层
- **DeepSeek API**：低温度设置提高判断准确性
- **系统指令**：冷酷客观的交易员视角，噪音自动忽略
- **结构化输出**：标的 → 属性（利好/利空）→ 理由
- **异常处理**：API 失败重试、速率限制退避

### 3️⃣ 去重存储层
- **SQLite 数据库**：本地持久化存储
- **GUID 索引**：快速查重，防止重复推送
- **推送状态追踪**：success / failed / filtered

### 4️⃣ 推送层
- **Telegram Bot**：稳定、快速、无需安装
- **PushDeer**：备选方案（国内友好）
- **即时推送**：判定为重大利好/利空立即发送

## 技术亮点

| 特性 | 实现方式 |
|------|---------|
| **低延迟** | 定时轮询 + 即时推送，抓取到推送 < 2 分钟 |
| **高准确率** | DeepSeek AI + 系统提示，只推送高置信度判断 |
| **自动去重** | SQLite GUID 索引 |
| **故障恢复** | 重试机制 + 异常捕获，单点失败不中断系统 |
| **易于扩展** | 模块化设计，数据源与 AI 角色可插拔 |

## 架构可迁移性

本项目的四层架构（RSS 采集 → AI 分析 → 去重存储 → 消息推送）与具体业务场景解耦：**数据源**（RSS 列表）与 **AI 角色**（系统提示词）都是可插拔配置。将 RSS 源切换为电力政策发布页、系统提示词切换为电力分析师视角，同一套架构即可用于电力政策监控、碳交易资讯跟踪等场景。

## 安全说明

- 所有 API 密钥存放在本地 `.env` 文件中（不提交仓库），通过 `python-dotenv` 加载
- 参考 `.env.example` 配置环境变量
- SQLite 数据库本地存储，不向外部服务上传原始数据
