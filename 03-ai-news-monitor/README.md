# AI 市场资讯智能监控系统

> **一句话简介**：7×24 小时自动监控加密货币市场资讯，AI 甄别重大利好/利空，1-2 分钟内推送到手机——把人工刷新闻的时间压缩掉 80%。

## 背景

加密货币市场资讯 24 小时滚动，重大消息（监管政策、ETF 审批、交易所事件）随时出现，但人工盯 RSS 源既慢又累：新闻噪音占比高，真正值得看的一天才几条。这个项目要解决的是——**让机器把"看新闻"这件事全干了，只把重要的推给人**。

## 做了什么

- **四层自动化架构**：RSS 采集 → DeepSeek AI 甄别 → SQLite 去重存储 → Telegram 即时推送
- **60 秒轮询**多 RSS 源，单源故障不影响整体；自动重试 + 超时控制
- **AI 甄别层**：系统提示词设定"冷酷客观的交易员"视角，要求 DeepSeek 以结构化格式输出「标的 → 利好/利空 → 理由」，噪音自动忽略——只推送高置信度判断
- **GUID 去重**：SQLite 索引保证同一新闻绝不重复推送
- **双渠道推送**：Telegram（主）+ PushDeer（备选，国内友好）
- **架构可插拔**：数据源列表与 AI 角色提示词均为配置项——换成电力政策 RSS + 电力分析师提示词，同一套架构即可迁移到电力政策/碳交易监控场景

## 成果数据

- 抓取到推送延迟 **< 2 分钟**（60 秒轮询 + 即时推送）
- 人工筛选时间压缩 **80%**（系统自动完成全部筛选，人只看推送结果）
- 推送成功率 > 99%（Telegram 可用性）
- 内存占用 < 50MB，空闲 CPU < 2%

## 技术栈

- Python（feedparser / requests / python-dotenv）
- DeepSeek API（结构化输出 + 速率限制退避重试）
- SQLite（GUID 索引去重）
- Telegram Bot API / PushDeer 推送

## 如何运行

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 配置密钥：复制 .env.example 为 .env，填入 DeepSeek 与 Telegram 密钥
# 3. 启动系统（60 秒轮询）
python main.py

# 或先看效果：演示模式（模拟数据，无需真实 API）
python demo.py
```
